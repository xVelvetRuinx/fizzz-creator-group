# Fizzz Creator Group

Recruitment landing page for @rheylia's Fizzz Creator Group.

## Site structure

- `index.html` — landing page content and SEO metadata
- `styles.css` — responsive Fizzz-inspired styling
- `script.js` — mobile navigation and Discord username copy button
- `.nojekyll` — serves the site as a plain static GitHub Pages site

## Publish with GitHub Pages

In this repository, open **Settings → Pages**.

Choose:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

Save. GitHub will display the public Pages URL after deployment.

## Important

This repository is public. Do not store applicant emails, IDs, payment information, contracts, private Discord messages, or other personal data here.
